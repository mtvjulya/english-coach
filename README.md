# English Coach

Бесплатное PWA-приложение для изучения английского: грамматика, словарный запас и разговорная практика. Работает полностью офлайн, без бэкенда и API-ключей. Устанавливается на телефон как приложение (PWA).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка в dist/ (PWA с офлайн-кэшем)
npm run preview    # проверка прод-сборки
```

Чтобы открыть на телефоне: запустите `npm run dev -- --host` и откройте `http://<IP-компьютера>:5173` в Chrome на телефоне (в одной сети Wi-Fi). Меню браузера → «Установить приложение».

## Три модуля

| Модуль | Что внутри |
|---|---|
| 📘 Грамматика | 10 тем A1–B1: теория на русском (правила, формулы +/−/?, примеры, сравнения, типичные ошибки, мини-тест) → практика (5 типов заданий, повторные попытки, объяснения) → перевод и устная практика (RU→EN, EN→RU, аудирование, своя речь) → освоение при 80%+ |
| 📖 Слова | 8 тем (~80 слов): карточки с озвучкой, транскрипцией, примерами, словосочетаниями, формами → практика (выбор перевода, ввод, аудирование, произношение) → интервальное повторение (SM-2) → активное использование (свои предложения, мини-текст, голосовой ответ) |
| 🎙️ Разговор | 6 сценариев (small talk, магазин, ресторан, телефон, врач, собеседование): аудирование с субтитрами/переводом/замедлением → проверка понимания → живой диалог с собеседником (голос или текст, фидбек после каждой реплики) → свободная речь 30–90 сек с анализом |

## Бесплатные технологии речи

- **Озвучка (TTS)** — Web Speech API `speechSynthesis` (встроено в браузер).
- **Распознавание речи (STT)** — Web Speech API `SpeechRecognition` (Chrome/Edge; в Firefox — ввод текстом).
- **Проверка переводов** — локальный движок: синонимы, нечёткое сравнение, приём альтернативных вариантов.

## Подключение настоящего AI (адаптер)

Вся «умная» логика идёт через интерфейс `AIProvider` (`src/engine/ai/types.ts`):

- `LocalAI` — сценарный офлайн-движок (по умолчанию, `src/engine/ai/local.ts`).
- `OpenAIProvider` — OpenAI-совместимый API: OpenAI, OpenRouter, Ollama, LM Studio (`src/engine/ai/openai.ts`).

Подключение — **Настройки → AI-собеседник** (или `.env`):

```env
VITE_AI_BASE_URL=https://api.openai.com/v1
VITE_AI_API_KEY=sk-...
VITE_AI_MODEL=gpt-4o-mini
```

Чтобы добавить свой провайдер — реализуйте `AIProvider` и зарегистрируйте его в `src/engine/ai/index.ts`. Остальной код менять не нужно.

## Структура

```
src/
  types.ts               — доменные типы
  engine/
    storage.ts           — прогресс/ошибки/SRS (zustand + localStorage)
    srs.ts               — интервальное повторение
    checker.ts           — проверка ответов, синонимы, теги ошибок
    speech.ts            — TTS/STT обёртки
    plan.ts              — план на день, рекомендации
    ai/                  — адаптер AI (types / local / openai / index)
  data/                  — контент: grammar/ vocab/ speaking/ placement
  screens/               — экраны
  components/            — UI-kit, плеер упражнений, аудио-кнопки
```

Весь прогресс — в `localStorage` (`english-coach-v1`), ничего никуда не отправляется.
